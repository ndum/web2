# Wahlthema «Dieselbe App in Angular»

Der Katalog von Lorraine Commons als Angular-Komponenten. `npm run build` übersetzt sie mit dem Angular-Compiler und prüft dabei die Templates. Um die App im Browser zu sehen, legst du mit der Angular CLI ein Projekt an und übernimmst die Dateien aus `src/app` und `data`.

```bash
npm install
npm run build
```
