Mit diesem Raster schätzt du ein, ob du für Teil 1 bereit bist. Lies jede Zeile und löse die Prüfaufgabe daneben, ohne nachzuschauen. Fällt sie dir leicht, hast du das Ziel erreicht. Wenn nicht, führt dich der Link in der letzten Spalte zur passenden Stelle.

| Ich kann … | Prüfaufgabe | Nachschlagen |
|---|---|---|
| erklären, wie ein Kapitel aufgebaut ist und wo ich Aufgaben, Tests und Lösungen finde | Zähle die Teile eines Kapitels in der richtigen Reihenfolge auf. | [Kursüberblick](../overview/#so-arbeitest-du) |
| beschreiben, was die App für die Mitglieder von Lorraine Commons leisten soll | Formuliere eine User Story nach dem Muster «Als Mitglied möchte ich …, damit …». | [Kursüberblick](../overview/#lorraine-commons) |
| KI-Werkzeuge so einsetzen, dass ich dabei lerne | Schreib eine Anfrage, die einen Hinweis statt einer Lösung verlangt, und nenne, was du im Projekt über deinen Einsatz von KI festhältst. | [Kursüberblick](../overview/#lernen-mit-ki) |
| Node.js, npm, Git und einen Editor für Vue einrichten | Gib im Terminal die Versionen von Node.js, npm und Git aus. | [Einrichten](../setup/) |
| ein Übungsprojekt installieren, testen und starten | Führe im Setup-Projekt `npm install`, `npm test` und `npm run dev` aus und öffne die App im Browser. | [Einrichten](../setup/#das-setup-projekt) |
| die Meldung eines fehlgeschlagenen Tests lesen | Ändere im Setup-Projekt den Namen in `App.vue` und erkläre, was die Meldung des Tests sagt. | [Einrichten](../setup/#aufgaben-und-tests) |
| in der Konsole der DevTools JavaScript ausführen und Fehlermeldungen lesen | Öffne die Konsole auf dieser Seite und gib `typeof null` ein. | [Einrichten](../setup/#die-devtools-des-browsers) |
| die Ausgabe von kurzem JavaScript-Code vorhersagen | Löse den Einstiegstest und arbeite die Einheiten durch, die er dir nennt. | [Einstiegstest](../entry-test/) |
| Werte, Funktionen, Objekte und Arrays in JavaScript sicher einsetzen | Löse die Aufgabe «Knobelei» der Einheit «Funktionen und Gültigkeitsbereich» ohne Hilfe. | [JS-Werkstatt](../../js/) |

Für Teil 1 brauchst du vor allem eine Einrichtung, die läuft, und die Grundlagen aus dem Einstiegstest. Was dir in der JS-Werkstatt noch fehlt, kannst du auch unterwegs auffrischen, die Kapitel verweisen auf die passenden Einheiten.
