Use this grid to judge whether you are ready for part 1. Read each row and solve the check task next to it without looking anything up. If it feels easy, you have reached the goal. If not, the link in the last column takes you to the right place.

| I can … | Check task | Look it up |
|---|---|---|
| explain how a chapter is structured and where to find exercises, tests and solutions | List the parts of a chapter in the right order. | [Course overview](../overview/#working-with-the-course) |
| describe what the app should do for the members of Lorraine Commons | Write a user story following the pattern "As a member, I want …, so that …". | [Course overview](../overview/#lorraine-commons) |
| use AI tools in a way that makes me learn | Write a request that asks for a hint instead of a solution, and name what you record about your use of AI in the project. | [Course overview](../overview/#learning-with-ai) |
| set up Node.js, npm, Git and an editor for Vue | Print the versions of Node.js, npm and Git in the terminal. | [Setup](../setup/) |
| install, test and start an exercise project | Run `npm install`, `npm test` and `npm run dev` in the setup project and open the app in the browser. | [Setup](../setup/#the-setup-project) |
| read the message of a failing test | Change the name in `App.vue` of the setup project and explain what the test's message says. | [Setup](../setup/#exercises-and-tests) |
| run JavaScript in the DevTools console and read error messages | Open the console on this page and type `typeof null`. | [Setup](../setup/#the-browser-devtools) |
| predict the output of short JavaScript code | Take the entry test and work through the units it names. | [Entry test](../entry-test/) |
| use values, functions, objects and arrays in JavaScript with confidence | Solve the "Challenge" exercise of the unit "Functions and scope" without help. | [JS workshop](../../js/) |

For part 1 you mainly need a setup that works and the basics from the entry test. Whatever you still lack from the JS workshop you can also refresh along the way, since the chapters point to the matching units.
