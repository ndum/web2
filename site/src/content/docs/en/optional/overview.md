The optional topics extend the course. You work through them on your own, usually when your project needs them. Each page explains briefly what the topic is about and when it pays off in a project, shows a small example and points to the official documentation. The optional topics are not part of the exam.

| Topic | Worth it when … |
|---|---|
| [TypeScript with Vue](../typescript/) | your project grows and you want to catch mistakes in props, events and data early |
| [Nuxt and server-side rendering](../nuxt-and-ssr/) | content should show up quickly and be found by search engines |
| [A backend of your own with Node](../backend/) | your app stores data that no public API provides |
| [Authentication](../authentication/) | only signed-in people may see or change certain data |
| [PWAs and offline use](../pwa/) | the app should be installable or work without a network |
| [Several languages](../several-languages/) | people with different languages use the app |
| [Animations and transitions](../animations/) | changes on the page should be easier to follow |
| [End-to-end tests with Playwright](../end-to-end-tests/) | the most important flows should be checked in a real browser |
| [Component libraries and CSS](../component-libraries-and-css/) | you'd rather not design forms, tables and dialogs yourself |
| [The same app in React](../same-app-in-react/) | you build your project with React |
| [The same app in Angular](../same-app-in-angular/) | you build your project with Angular |

Your own backend, authentication, end-to-end tests, TypeScript throughout and a PWA that works offline earn bonus points in the project, as the [project assignment](../../project/assignment/) describes. The runnable examples are in the folder `optional` of the course repo, the playground examples under `examples/optional`.
