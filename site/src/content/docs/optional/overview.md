Die Wahlthemen ergänzen den Kurs. Du bearbeitest sie selbständig, meist dann, wenn dein Projekt sie braucht. Jede Seite erklärt kurz, worum es geht und wann sich das Thema für ein Projekt lohnt, zeigt ein kleines Beispiel und verweist auf die offizielle Dokumentation. Zur Prüfung gehören die Wahlthemen nicht.

| Thema | Lohnt sich, wenn … |
|---|---|
| [TypeScript mit Vue](../typescript/) | dein Projekt wächst und du Fehler bei Props, Events und Daten früh sehen willst |
| [Nuxt und serverseitiges Rendern](../nuxt-and-ssr/) | Inhalte schnell sichtbar sein und von Suchmaschinen gefunden werden sollen |
| [Ein eigenes Backend mit Node](../backend/) | deine App Daten speichert, die keine öffentliche API liefert |
| [Authentifizierung](../authentication/) | nur angemeldete Personen bestimmte Daten sehen oder ändern dürfen |
| [PWA und Offline-Betrieb](../pwa/) | die App installierbar sein oder ohne Netz funktionieren soll |
| [Mehrere Sprachen](../several-languages/) | Menschen mit verschiedenen Sprachen die App nutzen |
| [Animationen und Übergänge](../animations/) | Änderungen auf der Seite leichter nachzuvollziehen sein sollen |
| [End-to-End-Tests mit Playwright](../end-to-end-tests/) | die wichtigsten Abläufe im echten Browser geprüft werden sollen |
| [Komponentenbibliotheken und CSS](../component-libraries-and-css/) | du Formulare, Tabellen und Dialoge nicht selbst gestalten willst |
| [Dieselbe App in React](../same-app-in-react/) | du dein Projekt mit React baust |
| [Dieselbe App in Angular](../same-app-in-angular/) | du dein Projekt mit Angular baust |

Für ein eigenes Backend, eine Authentifizierung, End-to-End-Tests, durchgehend TypeScript und eine PWA mit Offline-Betrieb gibt es im Projekt Bonuspunkte, wie der [Projektauftrag](../../project/assignment/) beschreibt. Die lauffähigen Beispiele liegen im Kursrepo im Ordner `optional`, die Beispiele für den Playground unter `examples/optional`.
