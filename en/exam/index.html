Exam

After part 7 you take a practical exam. It lasts 60 minutes and is open book, which means you may use your own notes and materials. There is no practice exam. The assessment page explains how the exam and the project count toward the module grade. This page describes the competences the exam covers and the topics and learning goals that go with them. Your teacher tells you which other aids are allowed and how the exam will run.

Competences

Section titled “Competences”

The course describes nine competences. The exam covers the first seven, which you build up in parts 0 to 7. After part 7 you can

  1. use the JavaScript features that SPA frameworks rely on, such as modules, destructuring, array methods and async and await,
  2. explain how an SPA is built and how it works, and tell it apart from web pages that the server renders,
  3. break an interface down into components and connect them with props, events and slots,
  4. use the reactivity of Vue on purpose and move reusable logic into composables,
  5. build client-side routing with params, nested routes and guards,
  6. place state on purpose (local, global, on the server or in the address) and manage shared state with Pinia,
  7. load and save data through an HTTP API and handle loading, error and empty states along the way.

You gain competences 8 and 9 in the project with part 8. You design an SPA of your own, record its decisions, test it, make it accessible and publish it. Along the way you use AI tools responsibly and review the code they generate. The project builds on competences 3 to 7.

Subject areas and learning goals

Section titled “Subject areas and learning goals”

The sections follow the parts of the course. Each one names the competences its part belongs to and sums up the learning goals of its chapters. The full list of learning goals is at the start of each chapter.

Part 0, Getting started

Section titled “Part 0, Getting started”

Part 0 sets up your working environment. After the chapter Setup you can install a project, start it, run its tests and read errors in the console of the DevTools. You need this for every practical task. The exam assumes the JavaScript basics that the entry test asks about.

Part 1, JavaScript for SPAs

Section titled “Part 1, JavaScript for SPAs”

Part 1 belongs to competence 1. Loading data with fetch also belongs to competence 7.

ChapterYou can …
Modules and packagessplit code with export and import, describe a project with package.json, install packages, run scripts and explain what the lock file is for
Values and referencestell primitive values and objects apart when assigning them, make shallow and deep copies of objects and arrays and change data without changing the original
Functions and arraysread callbacks, analyze lists with map, filter, find, some, every and reduce, sort without changing the original and write functions that build functions
Asynchronous JavaScriptpredict the order of timers and promises, work with async and await, load data with fetch, tell server errors from network errors, show loading and error states and abort requests

Part 2, SPA basics

Section titled “Part 2, SPA basics”

Part 2 belongs to competence 2.

ChapterYou can …
Web pages and web appsexplain how a multi-page website and an SPA load pages, place server-side rendering and statically generated pages, name the costs of an SPA and decide with reasons whether an SPA is worth it
An SPA by handbuild an interface from state and a render function, change the state through events, insert text safely into HTML and build a router on the hash of the address
Toolsdevelop and build an SPA with Vite, explain the dev server and hot module replacement, forward requests through a proxy, set environment variables and the base path and inspect requests in the DevTools

Part 3, Getting started with Vue

Section titled “Part 3, Getting started with Vue”

Part 3 lays the groundwork for competences 3 and 4.

ChapterYou can …
Frameworks comparedexplain the work a framework takes off an SPA, compare Vue, React and Angular, read survey numbers together with their limits and match the terms of the three frameworks
The first projectcreate a project with create-vue, explain its files, write a single file component, explain createApp and mount and use the Vue DevTools
Template syntaxbind values, attributes, classes and styles, show things conditionally with v-if and v-show, render lists with v-for and key and react to events with v-on
Reactive stateexplain why a plain variable does not update the page, hold state with ref and reactive, derive values with computed and choose between a function and a computed value
Formsbind fields with v-model and its modifiers, submit a form with @submit.prevent, validate input and show errors so that everyone notices them

Part 4, Components

Section titled “Part 4, Components”

Part 4 belongs to competence 3.

ChapterYou can …
Breaking down an interfacebreak an interface down into a tree of components with one job each, name and file the components and decide which component owns a piece of state
Propsdeclare props and their types with defineProps, pass values as text or as expressions, use required props and defaults and explain why data only flows from parent to child
Events and v-modeldeclare, emit and validate events with defineEmits, react to them in the parent and implement v-model on your own components with defineModel
Slotspass content through default slots, fallback content, named slots and scoped slots and build a page frame and an accessible dialog
Provide and injectprovide values with provide and receive them with inject, keep the keys in a file of their own, apply the rules for designing components and move content with Teleport

Part 5, Reactivity and composables

Section titled “Part 5, Reactivity and composables”

Part 5 belongs to competence 4.

ChapterYou can …
Reactivity in detailexplain how Vue tracks dependencies, find bugs with copied values and replaced objects, keep fields connected with toRef and toRefs, use shallowRef and wait for the updated page with nextTick
Watchersreact to changes with watch and watchEffect, use the options immediate, deep and once, clean up with onWatcherCleanup and choose between computed, watch and watchEffect
Lifecycle and template refsname the hooks of a component in order, reach elements with useTemplateRef, set the focus and add and clean up listeners and timers
Composablesmove state and logic into a composable, follow the rules for names, calls and return values, accept arguments with toValue and judge when a library such as VueUse fits

Part 6, Routing

Section titled “Part 6, Routing”

Part 6 belongs to competence 5.

ChapterYou can …
Vue Routerset up an app with Vue Router, show pages with RouterView and link them with RouterLink, name routes, style active links and tell history mode from hash mode
Params and querydefine and read routes with params, pass params as props, read and write the query and navigate with router.push and router.replace
Nested routes and layoutsbuild child routes and layouts with their own RouterView, set a start page for a section and tell active links from exactly active ones
Navigation guardsdescribe how a navigation runs, write global guards and guards for single routes, return to the original target after signing in and explain why a guard in the browser protects no data
Lazy loading and 404define a route for unknown addresses, load routes on demand, control scrolling with scrollBehavior and set the title and the focus after a navigation

Part 7, State and data

Section titled “Part 7, State and data”

Part 7 belongs to competences 6 and 7.

ChapterYou can …
State in the right placetell local, shared and global state, data from the server and state in the address apart, lift state into the parent or move it into a module and explain when an app needs no store
Piniaset up Pinia, write a setup store with state, getters and actions, take it apart with storeToRefs, use it in other stores and in guards and test stores
Data from an APIload data in an action, show loading, error and empty states, send data as JSON, evaluate the answers of the API, abort requests and explain when CORS is needed
Persistencekeep values as JSON in localStorage and sessionStorage, connect a store to the browser storage, keep tabs in sync, explain what never belongs in that storage and ask the server about a sign-in after a reload

Not part of the exam

Section titled “Not part of the exam”

The exam leaves out the two deep dives Proxies and getters and Server state libraries, the optional topics and part 8. The JS workshop is not a subject area of its own, but you need its basics in every task.

Section titled “Preparation”

The folder case in the course repo holds the state of the case app after every part. There you can see what the assignments of Martina Hostettler look like as finished code. Before the exam there is time for your questions, so bring the ones the grids raised.

Since you may use your own materials, it pays to keep them in order. File your solutions to the exercise projects and your notes so that you find them quickly. Looking things up helps with details, but 60 minutes leaves no time to learn a topic from scratch.
