# Lorraine Commons nach Teil 7

Das ist der Stand des Fallbeispiels nach Teil 7 «Zustand und Daten». Pinia hält Katalog, Anmeldung, Favoriten und Anfragen in Stores. Die Daten kommen von der Kurs-API, die Anmeldung hält eine Sitzung lang, die Favoriten bleiben in allen Tabs gleich, und ein angefangenes Formular bleibt in seinem Tab erhalten. Wenn du in Teil 7 nicht alles geschafft hast, startest du mit diesem Stand in Teil 8.

```bash
npm install
npm test
```

Für die App startest du die Kurs-API in einem Terminal, im Kursrepo im Ordner `api`, und Vite in einem zweiten:

```bash
npm start
npm run dev
```
