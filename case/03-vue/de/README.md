# Lorraine Commons nach Teil 3

Das ist der Stand des Fallbeispiels nach Teil 3 «Einstieg in Vue». Die App zeigt den Katalog mit Suche, Filter nach Kategorie und der Zahl der Dinge, die da sind. Jedes Ding hat eine eigene Seite mit einem Formular für die Reservationsanfrage. Die ganze App steht in App.vue. Wenn du in Teil 3 nicht alles geschafft hast, startest du mit diesem Stand in Teil 4.

```bash
npm install
npm test
```

Für die App startest du den Server in einem Terminal und Vite in einem zweiten:

```bash
npm run server
npm run dev
```
