# Lorraine Commons after part 3

This is the state of the running case after part 3 "Getting started with Vue". The app shows the catalog with a search, a filter by category and the number of things that are in. Every thing has a page of its own with a form for the reservation request. The whole app lives in App.vue. If you did not finish everything in part 3, start part 4 from this state.

```bash
npm install
npm test
```

For the app, start the server in one terminal and Vite in a second one:

```bash
npm run server
npm run dev
```
