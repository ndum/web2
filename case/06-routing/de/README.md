# Lorraine Commons nach Teil 6

Das ist der Stand des Fallbeispiels nach Teil 6 «Routing». Vue Router zeigt die Seiten für Katalog, Dinge, Favoriten und Verein, und Suche, Kategorie und Sortierung stehen in der Adresse. Das Team am Tresen meldet sich an und erfasst in seinem eigenen Bereich Rückgaben, und unbekannte Adressen bekommen eine eigene Seite. Wenn du in Teil 6 nicht alles geschafft hast, startest du mit diesem Stand in Teil 7.

```bash
npm install
npm test
```

Für die App startest du den Server in einem Terminal und Vite in einem zweiten:

```bash
npm run server
npm run dev
```
