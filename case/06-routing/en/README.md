# Lorraine Commons after part 6

This is the state of the running case after part 6 "Routing". Vue Router shows the pages for the catalog, the things, the favorites and the association, and search, category and sort order live in the address. The team at the counter signs in and records returns in an area of its own, and unknown addresses get a page of their own. If you did not finish everything in part 6, start part 7 from this state.

```bash
npm install
npm test
```

For the app, start the server in one terminal and Vite in a second one:

```bash
npm run server
npm run dev
```
