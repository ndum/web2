# Lorraine Commons nach Teil 4

Das ist der Stand des Fallbeispiels nach Teil 4 «Komponenten». Die App aus Teil 3 ist in Komponenten zerlegt. Die Karten haben Knöpfe zum Reservieren und für Favoriten, ein Dialog fragt vor dem Senden einer Anfrage nach, und das angemeldete Testmitglied steht im Kopf und im Formular. Wenn du in Teil 4 nicht alles geschafft hast, startest du mit diesem Stand in Teil 5.

```bash
npm install
npm test
```

Für die App startest du den Server in einem Terminal und Vite in einem zweiten:

```bash
npm run server
npm run dev
```
