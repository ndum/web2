# Lorraine Commons after part 4

This is the state of the running case after part 4 "Components". The app of part 3 is split into components. The cards have buttons to reserve and for favorites, a dialog asks before a request is sent, and the signed-in test member appears in the header and in the form. If you did not finish everything in part 4, start part 5 from this state.

```bash
npm install
npm test
```

For the app, start the server in one terminal and Vite in a second one:

```bash
npm run server
npm run dev
```
