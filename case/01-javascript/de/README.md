# Lorraine Commons nach Teil 1

Das ist der Stand des Fallbeispiels nach Teil 1 «JavaScript für SPAs». Es gibt noch keine Oberfläche, nur Hilfsfunktionen für den Katalog und eine Übersicht für den Tresen, die den Katalog vom Server des Vereins lädt. Wenn du in Teil 1 nicht alles geschafft hast, startest du mit diesem Stand in Teil 2.

```bash
npm install
npm test
```

Für die Übersicht startest du den Server in einem Terminal und die Übersicht in einem zweiten:

```bash
npm run server
npm start
```
