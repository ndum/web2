# Lorraine Commons after part 1

This is the state of the running case after part 1 "JavaScript for SPAs". There is no interface yet, only helper functions for the catalog and an overview for the counter that loads the catalog from the association's server. If you did not finish everything in part 1, start part 2 from this state.

```bash
npm install
npm test
```

For the overview, start the server in one terminal and the overview in a second one:

```bash
npm run server
npm start
```
