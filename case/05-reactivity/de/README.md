# Lorraine Commons nach Teil 5

Das ist der Stand des Fallbeispiels nach Teil 5 «Reaktivität und Composables». Die App merkt sich Suchtext, Kategorie und Favoriten im Browser, die Liste folgt dem Suchfeld nach einer kurzen Pause, und im Katalog steht der Fokus gleich im Suchfeld. Der Dialog schliesst mit Escape und führt den Fokus hinein und wieder hinaus. Wenn du in Teil 5 nicht alles geschafft hast, startest du mit diesem Stand in Teil 6.

```bash
npm install
npm test
```

Für die App startest du den Server in einem Terminal und Vite in einem zweiten:

```bash
npm run server
npm run dev
```
