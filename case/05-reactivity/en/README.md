# Lorraine Commons after part 5

This is the state of the running case after part 5 "Reactivity and composables". The app remembers search text, category and favorites in the browser, the list follows the search field after a short pause, and the focus starts in the search field of the catalog. The dialog closes with Escape and moves the focus into it and back out. If you did not finish everything in part 5, start part 6 from this state.

```bash
npm install
npm test
```

For the app, start the server in one terminal and Vite in a second one:

```bash
npm run server
npm run dev
```
