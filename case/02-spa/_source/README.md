# [%Lorraine Commons nach Teil 2|Lorraine Commons after part 2%]

[%Das ist der Stand des Fallbeispiels nach Teil 2 «SPA-Grundlagen». Die App zeigt den Katalog mit einer Suche und für jedes Ding eine eigene Seite, alles in JavaScript ohne Framework. Vite liefert sie aus, den Katalog liefert der kleine Server des Vereins. Wenn du in Teil 2 nicht alles geschafft hast, startest du mit diesem Stand in Teil 3.|This is the state of the running case after part 2 "SPA basics". The app shows the catalog with a search and a page of its own for every thing, all in JavaScript without a framework. Vite serves it, and the association's small server delivers the catalog. If you did not finish everything in part 2, start part 3 from this state.%]

```bash
npm install
npm test
```

[%Für die App startest du den Server in einem Terminal und Vite in einem zweiten:|For the app, start the server in one terminal and Vite in a second one:%]
