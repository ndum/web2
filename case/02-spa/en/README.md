# Lorraine Commons after part 2

This is the state of the running case after part 2 "SPA basics". The app shows the catalog with a search and a page of its own for every thing, all in JavaScript without a framework. Vite serves it, and the association's small server delivers the catalog. If you did not finish everything in part 2, start part 3 from this state.

```bash
npm install
npm test
```

For the app, start the server in one terminal and Vite in a second one:

```bash
npm run server
npm run dev
```
