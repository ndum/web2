# Lorraine Commons nach Teil 2

Das ist der Stand des Fallbeispiels nach Teil 2 «SPA-Grundlagen». Die App zeigt den Katalog mit einer Suche und für jedes Ding eine eigene Seite, alles in JavaScript ohne Framework. Vite liefert sie aus, den Katalog liefert der kleine Server des Vereins. Wenn du in Teil 2 nicht alles geschafft hast, startest du mit diesem Stand in Teil 3.

```bash
npm install
npm test
```

Für die App startest du den Server in einem Terminal und Vite in einem zweiten:

```bash
npm run server
npm run dev
```
