Glossar

Das Glossar erklärt die Fachbegriffe des Kurses kurz und verweist auf das Kapitel, das sie einführt. Viele Begriffe der Webentwicklung bleiben auch auf den deutschen Seiten englisch, etwa Props, Slots, Store, Router oder Composable. So findest du sie in der Dokumentation, in Fehlermeldungen und im Code wieder.

BegriffBedeutungKapitel
ADREin Architecture Decision Record hält einen Architekturentscheid mit Titel, Status, Kontext, Entscheid und Folgen in einer kurzen Datei fest.8.3
ActionEine Funktion in einem Store, die seinen Zustand ändert, oft nach einer Anfrage an den Server.7.2
AdapterEine Schicht, die eine fremde Schnittstelle wie fetch hinter eigenen Funktionen versteckt, damit sich die Umsetzung austauschen lässt.8.2
APIDie Schnittstelle, über die eine App Daten von einem Server holt und an ihn schickt. Im Kurs ist das die Kurs-API, die JSON über HTTP liefert.7.3
async und awaitEine Schreibweise, mit der sich asynchroner Code wie gewöhnlicher Code von oben nach unten liest. await wartet, bis ein Promise erfüllt ist.1.4
BarrierefreiheitEine App lässt sich auch mit der Tastatur, mit einem Screenreader oder mit starker Vergrösserung bedienen.8.5
BuildDer Schritt, in dem Vite den Code für die Veröffentlichung bündelt und verkleinert. Das Ergebnis liegt im Ordner dist.2.3
CallbackEine Funktion, die du einer anderen Funktion übergibst, damit diese sie später aufruft, etwa bei map oder bei einem Event.1.3
ClosureEine Funktion, die sich die Variablen der Umgebung merkt, in der sie entstanden ist.1.3
ComposableEine Funktion, die Zustand und Logik mit der Composition API bündelt, damit mehrere Komponenten sie verwenden. Ihr Name beginnt mit use.5.4
computedEin Wert, den Vue aus anderen reaktiven Werten berechnet und erst dann neu berechnet, wenn sich einer davon ändert.3.4
CORSCross-Origin Resource Sharing erlaubt einer Seite, Daten von einer anderen Herkunft zu lesen, wenn der Server dieser Herkunft es zulässt. Ohne diese Erlaubnis blockiert der Browser die Antwort.7.3
DeploymentDie gebaute App wird auf einem Server veröffentlicht, im Kurs auf GitHub Pages.8.6
DirektiveEin Attribut im Template wie v-if, v-for oder v-on, das Vue sagt, was es mit einem Element tun soll.3.3
EventEine Meldung einer Kindkomponente an ihre Elternkomponente, die sie mit emit auslöst.4.3
Event LoopDer Mechanismus, der wartende Aufgaben wie Timer oder Antworten vom Server ausführt, sobald der Aufrufstapel leer ist.1.4
FrameworkEin Grundgerüst, das einer App Aufgaben wie Rendern, Reaktivität und Routing abnimmt, etwa Vue, React oder Angular.3.1
GetterIn einem Store ein abgeleiteter Wert wie computed in einer Komponente. In JavaScript allgemein eine Funktion, die beim Lesen einer Eigenschaft läuft.1.5, 7.2
Hash-ModusRouting, bei dem der Pfad nach dem Zeichen # in der Adresse steht. Diesen Teil schickt der Browser nie an den Server.2.2, 6.1
History-ModusRouting mit gewöhnlichen Pfaden wie /items/6. Der Server muss dafür bei jeder Adresse die App ausliefern.6.1
Hot Module ReplacementVite ersetzt geänderte Teile wie CSS oder eine Vue-Komponente im laufenden Browser, ohne die ganze Seite neu zu laden.2.3
KomponenteEin Baustein der Oberfläche mit eigenem Template, eigener Logik und eigenem Stil.4.1
Lazy LoadingDer Code einer Route wird erst geladen, wenn jemand sie öffnet.6.5
LebenszyklusDie Phasen einer Komponente vom Erstellen über das Einhängen bis zum Entfernen. Hooks wie onMounted laufen in diesen Phasen.5.3
localStorageEin Speicher des Browsers, der Text pro Herkunft behält, auch nachdem der Browser geschlossen wurde.7.4
Lock-DateiEine Datei wie package-lock.json, die die genauen Versionen aller installierten Pakete festhält.1.1
ModulEine Datei mit eigenem Gültigkeitsbereich, die Werte mit export freigibt und mit import aus anderen Modulen holt.1.1
MPAEine mehrseitige Website, bei der jeder Klick auf einen Link eine neue HTML-Seite vom Server lädt.2.1
Navigation GuardEine Funktion, die Vue Router bei einer Navigation aufruft. Ein Guard vor dem Wechsel kann ihn erlauben, umleiten oder abbrechen.6.4
npmDie Paketverwaltung von Node.js. Sie installiert Pakete und startet die Skripte aus package.json.1.1
ParameterEin veränderlicher Teil eines Pfads wie :id in /items/:id.6.2
PersistenzZustand bleibt erhalten, wenn jemand die Seite neu lädt oder später wiederkommt.7.4
PiniaDie Bibliothek für Stores in Vue.7.2
PromiseEin Objekt für ein Ergebnis, das erst später feststeht. Ein Promise wird erfüllt oder abgelehnt.1.4
PropsWerte, die eine Elternkomponente an eine Kindkomponente übergibt. Die Kindkomponente liest sie, ändert sie aber nicht.4.2
Provide und InjectEine Komponente stellt mit provide einen Wert bereit, und Komponenten weiter unten im Baum holen ihn mit inject.4.5
ProxyIn JavaScript ein Objekt, das Zugriffe auf ein anderes Objekt abfängt, die Grundlage der Reaktivität von Vue. Bei Vite leitet ein Proxy des Entwicklungsservers Anfragen an einen anderen Server weiter.1.5, 2.3
QueryDer Teil der Adresse nach dem Zeichen ?, etwa ?q=säge, für Suche und Filter.6.2
ReaktivitätVue merkt sich, welche Werte ein Template oder ein computed liest, und aktualisiert die Oberfläche, wenn sich diese Werte ändern.5.1
refEin reaktiver Behälter für einen Wert. Im Script liest und schreibst du ihn über .value.3.4
Render-FunktionEine Funktion, die aus dem Zustand HTML erzeugt. Im Kurs baust du sie zuerst von Hand.2.2
RouteDie Zuordnung eines Pfads zu einer Seite der App.6.1
RouterDer Teil der App, der die Adresse liest und die passende Seite zeigt. In Vue ist das Vue Router.6.1
Server StateDaten, die dem Server gehören und die eine App nur zwischenspeichert, etwa der Katalog.7.5
sessionStorageEin Speicher des Browsers, der Text nur behält, bis der Tab geschlossen wird.7.4
Single File ComponentEine Datei mit der Endung .vue, die Template, Script und Stil einer Komponente enthält.3.2
Single Page ApplicationEine Webapp, die einmal lädt und danach die Seiten im Browser wechselt, ohne neue HTML-Seiten vom Server zu holen.2.1
SlotEin Platzhalter in einer Komponente, den die Elternkomponente mit eigenem Inhalt füllt.4.4
SSRBeim serverseitigen Rendern erzeugt der Server das HTML einer Seite, bevor der Browser es bekommt.2.1
StoreEin gemeinsamer Zustand mit Actions und Getters, den mehrere Komponenten verwenden.7.2
TeleportVue zeigt einen Teil einer Komponente an einer anderen Stelle im DOM, etwa einen Dialog am Ende der Seite.4.5
TemplateHTML mit der Syntax von Vue, aus dem Vue die Oberfläche einer Komponente erzeugt.3.3
Template-RefEin Verweis auf ein Element im Template, etwa um den Fokus zu setzen. In Vue holst du ihn mit useTemplateRef.5.3
TestCode, der prüft, ob anderer Code tut, was er soll. Im Kurs schreibst du Tests mit Vitest und Vue Test Utils.8.4
UmgebungsvariableEin Wert wie die Adresse der API, den Vite aus Dateien wie .env.local liest. Im Code steht er unter import.meta.env.2.3
v-modelEine Bindung in beide Richtungen zwischen einem Eingabefeld oder einer Komponente und einem Wert.3.5, 4.3
ViteEin Werkzeug mit Entwicklungsserver und Build für Webprojekte, das auch create-vue einrichtet.2.3
WatcherEine Funktion, die nach der Änderung eines Werts etwas auslöst, etwa Speichern oder eine Anfrage. In Vue schreibst du sie mit watch oder watchEffect.5.2
ZustandDie Daten, die sich eine App gerade merkt und aus denen sie die Oberfläche zeichnet.7.1
