# Aufgaben zu «Build und Deployment»

Die Aufgaben stehen im Kurs im Kapitel «Build und Deployment». So startest du das Projekt und die Tests:

```bash
npm install
npm run dev
npm test
```

Die Tests der ersten beiden Stufen bauen das Projekt mit Vite in einen temporären Ordner, das dauert ein paar Sekunden. Der Workflow der Knobelei läuft erst, wenn das Projekt in einem eigenen Repository auf GitHub liegt.
