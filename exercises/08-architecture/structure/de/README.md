# Aufgaben zu «Projektstruktur und Schichten»

Die Aufgaben stehen im Kurs im Kapitel «Projektstruktur und Schichten». So startest du das Projekt und die Tests:

```bash
npm install
npm run dev
npm test
```

Die Tests brauchen keinen Server. Für die App im Browser startest du in einem zweiten Terminal die Kurs-API, im Kursrepo im Ordner `api`:

```bash
npm start
```
