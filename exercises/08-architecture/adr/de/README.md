# Aufgaben zu «Architekturentscheide festhalten»

Die Aufgaben stehen im Kurs im Kapitel «Architekturentscheide festhalten». So startest du das Projekt und die Tests:

```bash
npm install
npm run dev
npm test
```

Die Aufgaben schreibst du in `docs/adr`. `template.md` zeigt den Aufbau eines Entscheids, die Tests prüfen Aufbau, Status und Verweise, den Inhalt nicht.
