# Aufgaben zu asynchronem JavaScript

Die Aufgaben stehen im Kurs im Kapitel «Asynchrones JavaScript». So installierst du das Projekt und startest die Tests:

```bash
npm install
npm test
```

Um den Katalog wirklich vom Server zu laden, startest du den Server in einem Terminal und die Übersicht in einem zweiten:

```bash
npm run server
npm run overview
```
