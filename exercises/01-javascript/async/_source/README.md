# [%Aufgaben zu asynchronem JavaScript|Exercises on asynchronous JavaScript%]

[%Die Aufgaben stehen im Kurs im Kapitel «Asynchrones JavaScript». So installierst du das Projekt und startest die Tests:|The exercises are in the course, in the chapter on asynchronous JavaScript. This is how you install the project and run the tests:%]

```bash
npm install
npm test
```

[%Um den Katalog wirklich vom Server zu laden, startest du den Server in einem Terminal und die Übersicht in einem zweiten:|To really load the catalog from the server, start the server in one terminal and the overview in a second one:%]

```bash
npm run server
npm run overview
```
