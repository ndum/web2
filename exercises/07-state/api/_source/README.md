# [%Aufgaben zu «Daten von einer API»|Exercises on data from an API%]

[%Die Aufgaben stehen im Kurs im Kapitel «Daten von einer API». So startest du das Projekt und die Tests:|The exercises are in the course, in the chapter on data from an API. This is how you start the project and the tests:%]

```bash
npm install
npm run dev
npm test
```

[%Die Tests brauchen keinen Server. Für die App im Browser startest du in einem zweiten Terminal die Kurs-API, im Kursrepo im Ordner `api`:|The tests need no server. For the app in the browser, start the course API in a second terminal, in the folder `api` of the course repo:%]

```bash
npm start
```
