# [%Aufgaben zur SPA von Hand|Exercises on the SPA by hand%]

[%Die Aufgaben stehen im Kurs im Kapitel «Eine SPA von Hand». So installierst du das Projekt und startest die Tests:|The exercises are in the course, in the chapter on an SPA by hand. This is how you install the project and run the tests:%]

```bash
npm install
npm test
```

[%Der Server liefert die App und den Katalog. Nach dem Start öffnest du http://localhost:3000/ im Browser.|The server delivers the app and the catalog. Once it runs, open http://localhost:3000/ in the browser.%]

```bash
npm run server
```
