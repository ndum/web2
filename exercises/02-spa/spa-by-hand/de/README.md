# Aufgaben zur SPA von Hand

Die Aufgaben stehen im Kurs im Kapitel «Eine SPA von Hand». So installierst du das Projekt und startest die Tests:

```bash
npm install
npm test
```

Der Server liefert die App und den Katalog. Nach dem Start öffnest du http://localhost:3000/ im Browser.

```bash
npm run server
```
