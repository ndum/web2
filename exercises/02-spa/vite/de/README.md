# Aufgaben zu den Werkzeugen

Die Aufgaben stehen im Kurs im Kapitel «Werkzeuge». So installierst du das Projekt und startest die Tests:

```bash
npm install
npm test
```

Die App startest du mit Vite, den Katalog liefert der kleine Server in einem zweiten Terminal:

```bash
npm run dev
npm run server
```
